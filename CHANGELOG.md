# Changelog

All notable changes to the Intellify plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Documentation improvements (README features, troubleshooting, usage guide)
- Plugin metadata fixes (vendor URL, since-build bump, action id correction with alias)

### Fixed
- Popup positioning now anchors to status bar widget instead of mouse cursor (fixes New UI out-of-bounds — #1)
- Corrected README badges and installation search term

## [0.0.7] - 2023-01-27
### Added
- Actions so key mappings can be applied (`Intellify Toggle Play / Previous / Next Track`)

## [0.0.6] - 2023-01-25
### Fixed
- Authorization issue (token refresh handling)

## [0.0.5] - 2023-01-24
### Added
- Progress bar for current song and improved feedback speed

## [0.0.4] - 2023-01-22
### Added
- Popup to control currently played song (album cover, playback buttons)

## [0.0.3] - 2023-01-20
### Fixed
- Compatibility fixes

## [0.0.2] - 2023-01-18
### Changed
- Plugin icon updated

## [0.0.1] - 2023-01-15
### Added
- Initial beta release — Spotify currently-playing status bar widget
